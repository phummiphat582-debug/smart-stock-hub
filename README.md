# ⚡ Smart Stock Hub (ระบบสต็อกและเบิกจ่ายกิจกรรมอัจฉริยะ ออนไลน์เรียลไทม์)

🌐 **ลิงก์เข้าใช้งานออนไลน์:** [https://phummiphat582-debug.github.io/smart-stock-hub/](https://phummiphat582-debug.github.io/smart-stock-hub/)

เว็บแอปพลิเคชันระบบจัดการสต็อกสินค้าและเบิกจ่ายอุปกรณ์กิจกรรมออนไลน์ อัปเดตข้อมูลสดเรียลไทม์ (Real-time Sync) ข้ามอุปกรณ์ ไม่ว่าจะเป็นมือถือ แท็บเล็ต หรือคอมพิวเตอร์ ออกแบบมาให้ใช้งานง่าย ลื่นไหล สวยงาม และแยกฐานข้อมูลอิสระ

---

## ✨ ฟังก์ชันเด่น (Key Features)

1. **📊 หน้าแดชบอร์ดสรุปภาพรวม (Real-time Dashboard):**
   - KPI สรุปจำนวนรายการ, คงเหลือรวม, มูลค่าสต็อกรวม (บาท), แจ้งเตือนสินค้าใกล้หมด
   - กราฟแท่งสถิติการเบิกใช้อุปกรณ์ย้อนหลัง 12 เดือน (Interactive Chart.js)
   - สรุปยอดการเบิกรายวัน, รายเดือน, หรือเลือกดูตามเดือนที่ต้องการ พร้อมพิมพ์รายงาน (Print) และส่งออก CSV

2. **📦 จัดการคลังสต็อก (Stock Inventory):**
   - ค้นหาอุปกรณ์ตามชื่อ, หมวดหมู่, หรือรหัสสินค้า
   - ตัวกรองสถานะ: สต็อกปกติ, ใกล้หมดเตือนสต็อกต่ำ ⚠️, หมดสต็อก ❌
   - ปุ่มปรับสต็อกด่วน (+1 / -1)
   - แสดงรูปภาพอุปกรณ์ พร้อมระบบดูภาพขยาย
   - รองรับการแก้ไขข้อมูล และลบรายการที่ไม่ใช้งาน

3. **➕ รับเข้าสต็อก / เพิ่มสินค้าใหม่ (Stock In & Restock):**
   - ระบบเติมชื่ออัตโนมัติ (Autocomplete) หากชื่อตรงกับสินค้าเดิมจะช่วยบวกจำนวนเพิ่มให้อัตโนมัติ
   - ตั้งราคาต่อหน่วย, กำหนดเกณฑ์แจ้งเตือนสต็อกต่ำ (Threshold)
   - อัปโหลดรูปภาพสินค้าได้หลายรูป พร้อมระบบบีบอัดภาพอัตโนมัติ

4. **📤 เบิกใช้อุปกรณ์ (Requisition & Withdraw):**
   - แสดงแถบยอดคงเหลือของอุปกรณ์ที่เลือกแบบเรียลไทม์
   - ปุ่มลัดเพิ่มจำนวน (+1, +2, +5, +10, ทั้งหมด)
   - คำนวณยอดคงเหลือหลังเบิกให้เห็นทันทีก่อนกดยืนยัน
   - บันทึกชื่อผู้เบิก, แผนก/ทีม, วัตถุประสงค์ และแนบรูปภาพใบเบิกหรือหลักฐานได้

5. **📜 ประวัติการเบิกและระบบยกเลิกคืนสต็อก (History & Undo):**
   - บันทึกประวัติการเบิกย้อนหลังทุกรายการ พร้อมวันเวลา
   - **ปุ่มยกเลิกการเบิก (Undo):** คืนจำนวนสินค้ากลับเข้าคลังสต็อกให้อัตโนมัติทันที
   - ตัวกรองช่วงวันที่เบิก และค้นหาตามชื่อผู้เบิก

6. **📂 นำเข้าข้อมูลด้วยไฟล์ CSV (Batch Import):**
   - ลากไฟล์ CSV มาวางเพื่อดูตัวอย่างข้อมูลก่อนนำเข้า
   - มีปุ่มดาวน์โหลดไฟล์ตัวอย่าง (Template CSV)
   - ตรวจจับอัตโนมัติว่ารายการใดเป็นสินค้าใหม่ หรือบวกเพิ่มในสินค้าเดิม

7. **⚡ ออนไลน์เรียลไทม์ & ใช้งานออฟไลน์ (Cloud Real-time & PWA):**
   - เชื่อมต่อ Cloud Firestore อัปเดตทันทีเมื่อเครื่องอื่นมีการเบิกหรือเพิ่มสต็อก
   - รองรับโหมดออฟไลน์และแคชข้อมูลในเครื่อง
   - ติดตั้งเป็นแอปพลิเคชันมือถือ (PWA) ลงหน้าจอโฮมได้

---

## 🚀 สถาปัตยกรรมและการติดตั้ง

- **Frontend:** Pure HTML5, Modern CSS3, JavaScript ES6+ (Zero Build Step)
- **Real-time Database:** Firebase Firestore Realtime Listener
- **Data Isolation:** จัดเก็บในคอลเลกชัน `smart_stock_items` และ `smart_stock_history` แยกเป็นอิสระ
- **Hosting:** GitHub Pages
